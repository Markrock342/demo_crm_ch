## Design Context

### Users
Chinese logistics operators on the China–Thailand corridor (freight forwarding, import/export, warehouse). Used in bright meeting rooms during a sales pitch and at ops desks.

### Brand Personality
ledger-house, measured, ink-and-seal

### Aesthetic Direction
Cool slate canvas, teal tracking seal accent (`--seal` hue 210). Light theme only. Ops-console density (Shopee Seller–like), not warm paper / cinnabar.

### Implementation Defaults
React 19 + Vite · global CSS tokens in `src/index.css` + `src/ui/kit.css` · custom kit (`src/ui/*`) · Phosphor icons regular 18px · no Tailwind / shadcn

### Design Principles
- Chinese-first copy; tabular cargo numerals
- Hierarchy via spacing and weight before color; surfaces via line + paper, not thick shadow
- One primary CTA per screen; AI lives in the inbox, never as a sparkle badge
- Workspace pages: toolbar → `stat-strip` → `table-shell` / dense list — no dead classes, no card-in-card
