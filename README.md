# 沧栈 CANGZHAN — เดโม CRM โลจิสติกส์ไทย–จีน

เดโมที่กดใช้ได้จริง มี Gemini ร่างจดหมายและสรุปตัวเลข คีย์ API อยู่บน server ไม่ลงเบราว์เซอร์

## รัน

คัดลอก `.env.example` เป็น `.env` แล้วใส่ `GEMINI_API_KEY`

```bash
cp .env.example .env
npm install
npm run dev
```

เปิด `http://localhost:5173` — Vite ส่ง `/api` ไปที่พอร์ต 8787

## ใช้ตอนเสนออะไร

1. **ภาพรวม** — TEU ในลาน เส้นออกไทย→จีน ปุ่มสรุปวันนี้ (Gemini)
2. **ลูกค้า** — มีระยองไทยฟู้ด / ยางสมุทรปราการ ส่งแหลมฉบัง→หยานเถียน/หนิงโป
3. **ตู้สินค้า** — กรองสถานะ รวมตู้รอ C/O ออกจีน
4. **ลานตู้** — กดตู้แล้วกดช่องว่างเพื่อย้าย
5. **จดหมาย** — กดให้ Gemini ร่างใหม่ หรือวางเมลเข้า คนกดส่ง เครื่องไม่ส่งเอง
6. **รายงานแผนก** — สรุปด้วย Gemini จากตัวเลขบนจอ + ส่งออก CSV
7. สวิตช์ **中文 / ไทย / EN**

ปุ่ม **คืนค่าเดโม** ในหน้าลูกค้า ล้างของที่แก้ในเครื่อง
